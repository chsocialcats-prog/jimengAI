# 会话人设与记忆修正设计

## 目标

在冒险输入区快捷指令下新增“修正人设”和“修正记忆”按钮。玩家的修正只作用于当前会话的后续 AI 回复，不修改剧本角色卡、世界书、其他会话或既有消息。

## 数据与优先级

会话新增两个 JSON 列表：`persona_corrections` 和 `memory_corrections`。每项包含文本与创建时间；新条目追加到列表，并保留最近 50 条。

生成 AI 上下文时，固定角色卡和世界书仍作为基础设定，自动剧情摘要作为历史参考；随后追加“会话人设修正”和“会话记忆修正”，并声明修正规则优先且必须遵守。会话开局回答保持原有优先级。

现有快照在创建时已经保存完整会话状态、消息和记忆摘要；修正字段将同时被纳入快照、读档恢复和自动存档，使恢复后的剧情保持一致。

## 交互

- 快捷指令区新增两个次级按钮。
- 点击后打开统一模态框，标题分别为“修正人设”“修正记忆”，包含说明与必填多行输入框。
- 确认后调用会话修正接口，显示保存成功提示，不主动请求 AI。
- 下次玩家发送行动时，AI 接收新的覆盖规则。
- 空输入在前端禁止提交，服务端返回 422；网络失败时保留模态框中的内容。

## 接口

`POST /api/conversations/{conversation_id}/corrections`：

```json
{ "kind": "persona", "content": "艾莲疲惫时话更少，但不会突然变得热情。" }
```

`kind` 仅允许 `persona` 或 `memory`。响应为更新后的会话。聊天请求和会话详情会返回两类修正，供前端保持状态一致。

## 测试与验收

- 后端测试修正持久化、类型与空值校验、50 条上限、提示词优先注入。
- 测试创建快照后修改修正，再读档能恢复旧修正。
- 手动验证两个按钮均能打开相应模态框；保存后下一轮 AI 回复遵从新内容；剧本原始角色卡内容不变。
