# NEKO 顶栏品牌与搜索布局设计

## 目标

让 NEKO 品牌回到网站左上角，并使搜索框以整个浏览器窗口为参照保持水平居中。左侧工作栏继续悬浮在视口左侧中部，其展开或收起都不能改变搜索框的位置。

## 已确认方案

采用全宽顶部玻璃栏：

- 顶部栏位于 `.app-shell` 的直接子级并横跨整个视口。
- NEKO 图标与字标放在顶部栏左侧，保持现有放大尺寸与玻璃质感。
- 搜索框位于顶部栏的几何中心，使用绝对居中或等效布局，不能以右侧 `.app-frame` 为参照。
- 故事系统状态保留在顶部栏右侧。
- 左侧工作栏移除品牌头部，只保留四个导航入口、AI 询问入口、模式和主题控制。
- 工作栏继续固定在视口左侧中部，圆形收起按钮和现有收起状态保持不变。
- 内容区域为全宽顶栏预留高度，现有 Hash 路由、主题、工作栏状态和导航接口不变。

## 响应式行为

- 桌面端：品牌在左，搜索框相对浏览器精确居中，状态在右。
- 960px 左右：搜索框可以缩窄，但中心点不偏移。
- 720px 以下：顶部栏改为两行，第一行显示品牌，第二行显示全宽搜索框；故事系统状态隐藏，底部导航维持现状。
- 页面不得出现横向溢出。

## 视觉约定

- 顶栏沿用 NEKO 的雾白玻璃材质、紫色细描边和轻量模糊。
- 品牌玻璃效果应融入顶栏，避免形成第二块突兀卡片。
- 搜索框继续使用半透明玻璃、紫色搜索图标和 `/` 快捷键提示。
- 不新增外部字体、图片或依赖。

## 兼容与测试

- 保留 `.brand`、`.brand-logo`、`.brand-text`、`.topbar-search`、`#global-search`、`#workspace-rail` 和 `#workspace-toggle`。
- 增加静态契约测试，验证品牌位于顶栏而非侧栏、顶栏是 `.app-shell` 的直接子级、搜索框以视口居中。
- 浏览器验证 1440px、960px 和 390px；检查搜索框中心、工作栏展开/收起后的位置稳定性、移动端两行布局和横向溢出。

## 范围外

- 本次不实现搜索数据逻辑。
- 不修改后端、API、SSE、路由、离线存储或冒险页业务行为。
