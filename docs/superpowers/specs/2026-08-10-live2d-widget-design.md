# Live2D 看板娘全站集成设计

日期：2026-08-10

状态：已获用户批准

## 目标

在 AI 对话冒险平台的所有前端页面中展示 Live2D 看板娘，并保留上游组件的关闭与重新唤起能力。页面路由切换时只保留一个看板娘实例，不增加后端接口、不修改对话数据，也不改变现有年龄确认和主题切换流程。

## 项目上下文

- 前端是 `frontend/index.html`、`frontend/css/style.css` 和原生 ES module 组成的单页应用。
- 页面通过 hash 路由切换首页、创作台、角色卡库、设置和冒险会话。
- `frontend/index.html` 是所有路由共用的宿主页面，因此适合放置一次性全局脚本。
- 上游 `live2d-widget` 提供 `dist/autoload.js`，该脚本会继续加载 `waifu.css` 与 `waifu-tips.js`，并初始化 Widget；模型资源由独立的资源仓库提供。

## 方案比较

### 方案 A：固定版本 CDN 自动加载（采用）

在共用 HTML 的 `body` 末尾加载 `live2d-widgets@1.0.1` 的 `autoload.js`。该方式与当前无 npm 构建流程的前端结构匹配，改动面小，且能够直接使用上游模型与工具栏。版本号固定，避免无意间跟随 CDN 的未审查更新。

代价是首次展示依赖外部网络，模型、Cubism Core 和提示资源不进入本项目仓库。

### 方案 B：将 Widget 运行时代码复制到项目内

把上游 `dist` 中的运行时文件复制到 `frontend/vendor`，再继续从外部加载模型。这样可以控制脚本缓存和版本，但会增加静态文件体积，并引入第三方文件同步与许可证维护成本。

### 方案 C：引入上游源码并建立构建流程

将 TypeScript 源码接入 npm/构建工具，以便深度定制。当前项目没有前端构建链，采用该方案会扩大任务范围，暂不选择。

## 交互与布局设计

1. Widget 在全站页面显示，包括首页、创作台、角色卡库、设置和冒险会话。
2. 脚本只在宿主页面加载一次；hash 路由切换不重新插入脚本，不创建重复的 `#waifu` 节点。
3. 使用上游自动加载脚本内置的工具栏，其中包含关闭入口；保留默认的 `showToggleAfterQuit` 行为，使关闭后仍显示重新唤起按钮。
4. 延续上游默认的不可拖动设置，避免看板娘覆盖聊天输入区后难以恢复；如需拖动，后续可独立调整。
5. 桌面端沿用上游左下角定位。补充必要的本地 CSS 兼容规则：弹窗和移动端底部导航必须位于 Widget 之上，Widget 不得阻断模态层交互。
6. 移动端保留看板娘，但缩小模型并将其放置在底部导航上方；提示气泡和工具栏不得遮挡输入控件。

## 加载与失败处理

加载顺序如下：

1. 页面按现有顺序加载应用样式和 `main.js`。
2. 在 `body` 末尾加载固定版本的 `autoload.js`。
3. `autoload.js` 异步加载上游样式、提示逻辑、Cubism Core 和模型资源。
4. Widget 初始化完成后由上游脚本维护显示、关闭和重新唤起状态。

Widget 是非核心增强功能。任何外部资源加载失败都不能阻止应用初始化、路由、对话和设置功能；失败时允许看板娘不显示，并将问题限制在浏览器控制台，不新增应用内错误弹窗。

## 文件边界

- `frontend/index.html`：增加一次性、固定版本的 Widget 加载入口。
- `frontend/css/style.css`：增加 Widget 与现有 topbar、modal、移动端底部导航之间的层级和尺寸兼容规则。
- `frontend/test_live2d_widget.mjs`：增加静态契约测试，确认脚本只出现一次、版本被固定、关闭后重新唤起配置未被禁用。
- 不修改 `backend/`、路由逻辑、数据库结构和会话状态。

## 验收标准

- 启动网站后，首页可以看到 Live2D Widget 或在外部资源不可用时保持页面正常工作。
- 切换到创作台、角色卡库、设置和冒险页面时，页面始终只有一个 Widget 实例。
- 点击关闭后，重新唤起按钮可见并能恢复 Widget。
- Widget 不遮挡桌面端顶部导航、弹窗；移动端不覆盖底部导航和聊天输入区。
- 现有前端静态测试、后端测试和启动浏览器检查全部通过。
- 不出现新增后端请求、持久化用户信息或未固定版本的 Widget 资源引用。

## 许可与资源说明

本项目只引用上游发布的运行时入口，不复制模型文件。部署环境需要允许访问相应 CDN，并应遵守 `live2d-widget` 的 GPL-3.0 条款、Live2D Cubism 相关许可，以及模型资源作者的使用限制。该组件的模型资源不属于本项目自有资产。
