# 聊天回复时间与字数信息设计

## 目标

在 AI 回复气泡的右下角显示该条回复的发送时间和当前回复字数，帮助用户判断回复的新鲜度和内容长度。

## 交互与视觉

- 仅在回复内容输出完成后显示信息栏；流式输出中的气泡不显示，避免显示不断跳动的中间统计。
- 信息格式为 `发送时间    字数`，两项之间使用较明显的空白间距，不使用圆点或其他分隔符。
- 信息栏右对齐，使用小号、低对比度字体，不抢正文阅读焦点。
- 历史 AI 回复和当前新生成的 AI 回复都显示相同的信息栏。

示例：

```text
2026-08-11 14:18    856 字
```

## 计算规则

- 时间使用消息已有的 `created_at` 字段，并沿用现有 `formatTime` 格式化逻辑。
- 字数统计回复的可见文本，去除空格、换行和其他空白字符后，按 Unicode 字符数量计算；中文标点计入。
- 不新增数据库字段，也不改变 API 协议；历史消息直接使用已有时间字段。

## 实现边界

- 前端抽取一个纯函数生成回复元信息 HTML，供历史消息渲染和流式完成后的 DOM 更新复用。
- `messageHtml` 为已完成的 AI 消息渲染元信息；`sendMessage` 在流式完成并确定最终文本后追加同样的信息栏。
- 用户消息和系统消息不增加字数栏，避免把“当前回复字数”误解为用户输入长度。
- 增加小屏样式，保证信息栏在气泡内右对齐且不撑破布局。

## 验收标准

1. 已完成 AI 回复右下角显示时间和字数。
2. 时间与字数之间没有圆点，间距明显，字体小且颜色较浅。
3. 历史消息刷新后仍显示正确的时间和字数。
4. 流式输出期间不显示元信息，完成后显示最终字数。
5. 空格和换行不计入字数，中文标点计入。
6. 现有前后端测试全部保持通过。
