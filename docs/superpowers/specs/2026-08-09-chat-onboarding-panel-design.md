# 聊天内开局资料与引导面板设计

## 目标

新建冒险后直接进入聊天页面，并在聊天对话框内弹出开局面板。面板集中展示该剧本的开场、角色状态、世界书的当前事件/环境/记忆和会话引导字段；用户确认后才能发送第一条消息。已有会话不重复弹出，但可只读回顾。

## 行为

- 新建会话始终导航到聊天页；如果该会话为 `pending`，聊天页显示强制开局面板并禁用输入。
- 面板显示开场文本、角色卡关键字段、世界书条目和动态引导表单。
- 提交引导后调用既有 onboarding 接口，隐藏面板，保留开场消息并启用输入。
- 没有引导字段的剧本显示资料预览与“确认开始”；确认后会话标记完成。
- 已完成会话顶部提供“开局设定”按钮，仅展示只读资料和本会话回答。

## 前端边界

复用现有 `renderAdventure`、`renderOnboarding` 的数据加载与提交逻辑，将表单渲染提取为可嵌入的面板函数；删除独立 `#/onboarding/{id}` 页面路由。作品详情仍显示摘要和会话列表，但不承担首次引导。

## 验收

- 新建会话打开聊天界面后立即看到资料与引导，输入框不可用。
- 确认后输入框可用，后续进入不再弹窗。
- 顶部回顾按钮可查看资料，不允许修改已完成答案。
- 前端语法检查与现有后端测试通过。
