# NEKO 品牌区设计规格

## 背景

网站当前左上角使用指南针图标和“AI 对话冒险”文字作为品牌标识。用户提供了一张紫粉渐变猫咪图标，并确认将品牌字标改为 `NEKO`，采用轻盈几何无衬线风格。

## 目标

- 用用户提供的猫咪图标替换左上角旧指南针图标。
- 用 `NEKO` 替换左上角旧品牌文字。
- 将浏览器标签标题改为 `NEKO · AI 对话冒险`。
- 让新品牌区在现有浅色/深色主题和移动端断点下保持清晰、稳定。

## 非目标

- 不修改导航名称、页面路由、业务逻辑或数据结构。
- 不将作品封面、页面说明、Live2D 欢迎语等内容中的“AI 对话冒险”统一重命名；这些文字不属于左上角品牌区。
- 不重新设计猫咪图标本身，只为网页使用准备合适的资源版本。

## 设计方案

### 品牌区结构

`frontend/index.html` 的 `.brand` 保留为返回作品库的链接，但删除旧的指南针图标节点和旧品牌文字节点，替换为：

- 一个新的猫咪图标图片元素，使用网页专用的透明、紧裁切资源。
- 一个显示 `NEKO` 的字标元素。

品牌链接继续保留现有的无障碍标签“返回作品库”。图片使用空 `alt`，避免重复朗读链接标签。

### 图标资源

将用户提供的 PNG 作为源素材，生成放入 `frontend/assets/` 的网页专用图标资源。源图预览包含棋盘格背景且没有常规 alpha 通道，因此网页资源需要移除棋盘格并裁切到猫咪主体，同时保留原有紫粉渐变、耳朵、表情和尾部轮廓。

CSS 以约 34px 的桌面尺寸显示图标，在小屏断点下降至约 30px；图标使用 `object-fit: contain`，不拉伸、不裁掉猫耳或尾部。

### NEKO 字标

字标采用本地系统字体栈，避免新增外部字体网络依赖。使用大写、偏粗的几何无衬线字形，增加字距以形成品牌感；颜色使用与图标协调的紫色系渐变或主题兼容的高对比色。桌面端保持约 17px 的视觉重量，移动端适度缩小，但不隐藏或换行。

### 标题与范围

将 `<title>` 改为 `NEKO · AI 对话冒险`。左上角不再出现旧指南针图标或“AI 对话冒险”品牌文字；其它页面内容中的同名描述保持不变，避免混淆产品描述和品牌名称。

## 响应式行为

- 桌面端沿用现有顶部栏高度、导航位置和右侧操作区布局。
- 720px 以下沿用现有顶部栏换行与底部导航规则，仅缩小品牌图标和字标。
- 420px 以下继续使用紧凑图标尺寸，确保右侧模式徽章和主题切换按钮可用。
- 不改变 `.brand` 链接的点击目标与键盘焦点样式。

## 实现边界

预计只涉及：

- `frontend/index.html`：品牌节点和文档标题。
- `frontend/css/style.css`：品牌图片、字标、响应式尺寸与主题下的颜色样式。
- `frontend/assets/`：由用户源图生成的网页专用图标资源。

如果资源处理需要临时文件，临时文件不应进入提交；不修改当前工作区中与本需求无关的未提交改动。

## 验证

- 静态检查：旧品牌区中的 `data-icon="compass"` 和 `AI 对话冒险` 字标节点已删除，`NEKO` 和新图片路径存在。
- 资源检查：图标文件可由前端静态路径加载，背景透明，主体完整。
- 浏览器检查：浅色和深色主题下品牌区均可读，图标不出现棋盘格、变形或溢出。
- 响应式检查：桌面、720px 以下和 420px 以下宽度下，品牌区不挤压导航和右侧操作。
- 回归检查：运行现有前端相关测试，并确认品牌链接仍可返回作品库。
