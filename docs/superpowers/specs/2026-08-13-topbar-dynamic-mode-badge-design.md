# 右上角动态模式徽标设计

## 目标

将左侧工作栏中的动态运行模式徽标移动到网页右上角，用它替换并删除静态的“故事系统就绪”提示。

## 界面行为

- 右上角继续使用现有的 `#mode-badge`，根据运行状态动态显示“DeepSeek 在线”“Mock 模式”或“离线演示”。
- 删除左侧工作栏的整个 `.workspace-status` 状态块，包括“本地故事引擎”文案、状态圆点和原有占位；左侧底部只保留主题切换按钮。
- 完全删除右上角静态的“故事系统就绪”文案，不保留第二套状态显示。
- 沿用现有模式检测和文案更新逻辑，不改变后端接口、数据流或模式判断规则。

## 实现范围

- 调整 `frontend/index.html` 中 `#mode-badge` 的 DOM 位置。
- 对 `frontend/css/style.css` 做最小样式调整，使右上角徽标与仅剩主题按钮的左侧底部保持正确对齐。
- 不改变全局搜索、主题切换、导航、故事生成或设置功能。

## 响应式与可访问性

- 徽标位于 `.top-actions` 内，桌面端与窄屏端都随顶部栏现有响应式规则排列。
- 保留 `#mode-badge` 现有标题说明及可读文本；状态不能只靠颜色表达。

## 验证

- 添加或更新前端界面契约测试，确认 `#mode-badge` 位于 `.top-actions`，且左侧工作栏不再包含 `.workspace-status`、“本地故事引擎”或状态圆点。
- 确认页面源码中不再出现“故事系统就绪”。
- 确认在线、Mock 和离线三种模式仍可更新同一个徽标的文案。
- 运行相关前端测试，再运行完整前端测试套件；若改动仅限静态前端布局，不需要修改后端测试。
