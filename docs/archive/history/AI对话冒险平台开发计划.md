# AI 对话冒险平台开发计划（草案 v0.2）

## 1. 产品定位

**一句话：** 一个让用户使用自己的 AI API Key，创建、分享并游玩高自由度 AI 对话冒险的平台。

核心体验：
- 选择或自定义「角色卡」与「世界书」，像打开一本书一样进入剧情。
- 既可以自由输入行动，也可以点选项、按钮、快捷指令。
- AI 负责角色扮演、旁白、剧情推进、判定和状态变化。
- 玩家的选择会影响状态、好感、物品、任务和后续剧情，并支持多存档、回退、分支。

## 2. 核心玩法

1. **开局设定**：选择预设作品，或自定义角色、世界背景、开场剧情。
2. **自由交互**：聊天式输入 + 剧情选项，支持多角色对话和旁白演出。
3. **状态系统**：属性、物品、金钱、好感度、任务、状态 buff。
4. **判定系统**：骰子、战斗、成功/失败、大成功/大失败。
5. **记忆系统**：短期记忆 + 长期摘要 + 关键设定持久化，防止角色失忆、人设崩塌。
6. **存档系统**：多存档位、自动存档、回到历史节点、时间线分支。
7. **创作者生态**：发布作品、编辑卡片、版本更新、评分收藏、评论区反馈。

## 4. 界面设计

### 4.1 页面结构

- **首页/探索页**：推荐位、热榜、分类标签、搜索栏、作品卡片
- **作品详情页**：封面、简介、标签、评分、作者、开始游玩 / 收藏
- **冒险页**：核心页面，沉浸式对话 + 状态信息
- **创作台**：角色卡、世界书、开场、测试对话
- **个人中心**：我的作品、我的游玩、存档、API 设置、用量
- **管理后台**：用户、作品、审核、举报、用量监控

### 4.2 冒险页布局建议

```text
+----------------------+----------------------+-------------------+
| 顶部栏：返回/标题/设置 | 剧情标题/章节        | 操作按钮          |
+----------------------+----------------------+-------------------+
| 对话正文区           | 对话正文区           | 状态侧栏          |
| （流式输出）         | （选项按钮）         | 属性/物品/好感/任务|
+----------------------+----------------------+-------------------+
| 底部输入区：自由输入 + 快捷指令 + 骰子 + 存档按钮              |
+---------------------------------------------------------------+
```

移动端：状态侧栏收进抽屉，底部固定输入栏，对话区全宽。

### 4.3 设计原则

- 暗色沉浸主题为主，明亮模式可选；避免大面积单色渐变和廉价“光球”装饰。
- 对话区用干净的卡片/气泡，保持文字可读性，不堆叠多层卡片。
- 选项按钮、指令按钮、图标按钮都有稳定尺寸和悬停反馈。
- 角色卡封面、立绘、CG 使用真实图片/生成图，不用纯 SVG 当主视觉。
- 所有文本保证移动端不溢出、不互相遮挡。

## 5. 技术架构

### 5.1 推荐选型（可按你的情况调整）

| 层 | 方案 |
| --- | --- |
| 前端 | React / Next.js + TypeScript + Tailwind，移动优先 |
| 后端 | Node.js (NestJS/Express) 或 Python (FastAPI) |
| 数据库 | PostgreSQL + Redis（缓存/会话/限流） |
| 存储 | 本地磁盘或 S3/OSS，存图片、立绘、导出包 |
| 部署 | Docker + Nginx，单机起步，后续可扩展 |
| AI 接入 | DeepSeek 官方 API，OpenAI 兼容格式，流式输出 |

### 5.2 AI 接入层（关键）

- 已确认接入 DeepSeek：`baseURL = https://api.deepseek.com`，模型以 `deepseek-chat` 为主，`deepseek-reasoner` 作为备用。
- 兼容 OpenAI 格式，后端统一封装请求、流式接收、超时、重试、Token 统计。
- API Key 只保存在本机配置文件（如 `config.json` / `.env`），不打包进程序，不上传任何服务器。
- 全部使用流式输出（SSE），前端打字机效果。
- 一个请求里的上下文由「系统人设 + 世界书 + 固定设定 + 记忆摘要 + 最近对话 + 当前状态」组成。
- 状态变化、判定结果通过结构化输出或工具调用（function calling）返回，前端解析后更新面板。

### 5.3 上下文与记忆策略

1. **固定区**：角色卡人设、世界观、规则，始终注入。
2. **世界书区**：按关键词/标签触发对应条目。
3. **动态区**：最近 N 轮对话。
4. **摘要区**：当对话过长时，把旧内容压缩成摘要。
5. **状态区**：属性、物品、任务以 JSON 形式注入，AI 按规则修改。

### 5.4 核心数据模型（简版）

```text
User         用户：账号、API Key、设置
Work         作品：角色卡 + 世界书 + 开场 + 封面 + 标签
Card         角色卡：人设、性格、语气、关系、画像
WorldBook    世界书：条目、关键词、内容、优先级
Conversation 冒险会话：作品、用户、进度、状态快照
Message      消息：role、content、metadata
Snapshot     存档：完整状态 JSON、时间戳、分支信息
State        实时状态：属性、物品、好感、任务、日志
Comment      评论、评分、收藏、举报
```

角色卡 JSON 示例：

```json
{
  "name": "角色名",
  "persona": "身份、性格、说话方式、记忆锚点",
  "world": "所在世界的规则与背景",
  "opening": "开场剧情文本",
  "directives": ["保持人设", "结局由玩家行为决定"],
  "initial_state": {
    "attributes": { "魅力": 60, "武力": 40 },
    "items": [],
    "relations": {}
  }
}
```

## 6. 安全与合规

- **未成年保护**：注册需年龄确认；涉及成人内容必须有明确年龄门槛。
- **内容红线**：平台必须禁止任何涉及未成年人的色情内容，无论虚构与否。
- **个人自用**：所有作品、对话、存档只存本机，不做云端同步。
- **启动确认**：首次启动显示 20+ 内容确认提示，确认后才能进入。
- **API 审查风险**：DeepSeek 官方 API 可能对部分成人内容有限制；如果被拒绝，先优化提示词，必要时可预留本地模型（如 Qwen/Ollama）作为备选接入。
- **API Key 安全**：存本机配置文件，设置可修改，不写死在代码里。

## 10. 工作流拆分建议

### 方案 A：顺序工作流（推荐第一版）

| 工作流 | 内容 | 完成标准 |
| --- | --- | --- |
| W1 骨架与启动 | 项目结构、配置文件、启动脚本、SQLite 初始化 | 一条命令能启动，本地打开空页面 |
| W2 DeepSeek 接入 | API 配置、流式对话、错误提示、用量统计 | 页面里输入文字能收到 AI 流式回复 |
| W3 冒险引擎 | 角色卡/世界书、上下文组装、记忆摘要、状态/骰子、存档 | 能玩完一次完整冒险并读档 |
| W4 前端界面 | 作品库、冒险页、状态面板、创作台、设置页 | 常用操作全在界面上完成 |
| W5 联调打磨 | 端到端测试、20+ 确认、中文 UI 细节、打包 `.exe` | 独立打包后也能正常使用 |

优点：个人自用项目规模不大，顺序做最不容易出现接口对不上、文件互相覆盖的问题，每一步都有可运行的结果。

### 方案 B：并行多线程（以后需要加速时再用）

前提是先冻结「API 接口契约 + 数据模型」，否则并行只会增加联调成本。

| 线程 | 内容 |
| --- | --- |
| 线程 A | 前端 UI：作品库、冒险页、状态面板、创作台 |
| 线程 B | 后端 API + DeepSeek 接入 + SQLite |
| 线程 C | 冒险引擎：记忆、状态、骰子、存档 |
| 主线程 | 汇总代码、联调、测试、打包 |

### 建议

第一版按方案 A 顺序执行，W1-W5 每个工作流独立完成、独立可运行；如果后续想加速，再在 W3/W4 之后把前后端拆成并行线程。每个工作流开始前会先说明改动范围，避免重复劳动。

## 11. Codex 多对话分工

这个项目将拆成多个 Codex 对话（线程），每个对话负责一个工作流，由主线程统一计划和联调：

| 对话 | 职责 | 依赖 |
| --- | --- | --- |
| 主线程（当前） | 需求、计划、接口契约、汇总联调、打包 | 无 |
| W1 骨架与启动 | 项目结构、配置文件、启动脚本、SQLite 初始化、空页面 | 无 |
| W2+W3 后端引擎 | DeepSeek 接入、流式对话、冒险引擎、记忆、状态、骰子、存档 | W1 |
| W4 前端界面 | 作品库、冒险页、状态面板、创作台、设置页 | W1 |
| W5 联调打磨 | 端到端测试、20+ 确认、打包 `.exe` | 全部完成 |

创建顺序：先创建并完成 W1，再创建后端引擎和前端界面两个对话，最后回到主线程做 W5 联调。每个对话开始时都会先读这份计划，避免各线程理解不一致。
